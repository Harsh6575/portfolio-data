A full-stack hospitality marketplace inspired by Airbnb, covering the
end-to-end booking experience: authentication, property listings with image
galleries, geospatial search via React-Leaflet, and a real-time reservation
workflow backed by Prisma and PostgreSQL.

## Key Highlights

- User authentication and authorization system
- Property listing with image galleries
- Advanced search and filtering options
- Interactive maps integration
- Booking system with date selection
- Responsive design across all devices
